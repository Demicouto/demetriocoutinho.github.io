# Game List Implementation Plan

> **For agentic workers:** Implementar diretamente nesta sessão, seguindo a aprovação visual já recebida e a preferência do usuário por uma etapa por projeto.

**Goal:** Integrar o cartão e os detalhes aprovados do Game List ao portfólio local.

**Architecture:** HTML estático e um diálogo nativo, com CSS e JavaScript próprios da seção. As traduções entram no sistema existente. Não há dependências novas.

**Tech Stack:** HTML, CSS, JavaScript e os recursos já presentes no portfólio.

**Spec:** `docs/superpowers/specs/2026-11-10-game-list-design.md`

## Global Constraints

- Seguir a prévia aprovada do Game List.
- Manter o conteúdo coerente com a contribuição colaborativa confirmada.
- Apresentar exemplo antes de implementar cada projeto seguinte.

## Review Focus

- Cartões com alturas diferentes e mudança de largura: a primeira linha deve permanecer acessível.
- Teclado: abrir, fechar com Escape e devolver o foco.
- Celular: janela rolável, capturas proporcionais e ausência de largura excessiva.
- Tema escuro e idiomas: cores herdadas e todas as novas chaves traduzidas.
- Fontes e imagens tardias: recalcular a área da grade sem cortar o botão.
