# Marie Claire no portfólio

Prévia `marie-claire-cartao-v2.html` aprovada pelo usuário após inclusão do painel administrativo. Implementação local: cartão com preview, abertura por imagem/título e diálogo com página inicial, dashboard e catálogo. O projeto aparece como em desenvolvimento.

## Conteúdo aprovado

Participação em interface, API e banco de dados. Tecnologias: Next.js, React, TypeScript, CSS Modules, Express, Prisma, PostgreSQL e JWT. Desafio: conectar a vitrine à gestão da doceria. Solução: API modular, persistência, carrinho local, checkout autenticado, encaminhamento do pedido pelo WhatsApp e administração de pedidos, produtos e ingredientes.

## Capturas

As imagens mostram o front-end real do repositório `marie-claire-doceria-fullstack`, executado localmente. Página inicial e catálogo usam os dados de exemplo já disponíveis no front-end quando não há API conectada. O dashboard foi renderizado em contexto de navegador isolado com fixtures locais inspiradas no seed: um pedido, quatro produtos, três ingredientes e valores financeiros demonstrativos. Nenhuma conta real ou dado de cliente foi acessado para essa captura. As legendas e o texto informam que os dados são demonstrativos.
