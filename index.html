O desafio

Mai-Dai · Detalhes do projeto

Capturas reais do aplicativo · clique para ampliar

Pesquisa aplicada · Bolsa FACEPE

Mai-Dai

Uma plataforma para acompanhar medições de sistemas fotovoltaicos e analisar dados históricos com um modelo de inteligência artificial.

Minha contribuição: Atuação full-stack como bolsista FACEPE, desde outubro de 2026, nas interfaces, na API, na integração com sensores e IA e nos testes automatizados.

Tecnologias utilizadas

  • HTML
  • CSS
  • JavaScript
  • TypeScript
  • NestJS
  • TensorFlow.js
  • Firebase

O desafio

Integrar fontes diferentes — registros históricos em CSV e medições de sensores ESP32 — preservando as fórmulas do modelo e identificando leituras ausentes ou inválidas.

Como resolvemos

A API separa o fluxo CSV com inferência do fluxo de sensores pelo Firebase. A integração valida as medições e seus horários, trata falhas de comunicação e preserva a normalização das 20 entradas do modelo. A interface consulta a API automaticamente a cada 30 segundos.

5.080 registros

Base histórica utilizada na comparação da refatoração.

20 entradas

Normalização preservada para a inferência do modelo.

A previsão usa o CSV histórico. As medições dos sensores são exibidas com sua disponibilidade; esse fluxo ainda não fornece todas as entradas exigidas pela IA.

Full-stack · Em desenvolvimento

Marie Claire Doceria

Um sistema para apresentar os produtos de uma doceria, organizar encomendas e apoiar a gestão de pedidos, produtos e ingredientes.

Minha contribuição: Participei das interfaces, da API e do banco de dados, conectando a experiência de compra às funcionalidades administrativas.

Tecnologias utilizadas

  • Next.js
  • React
  • TypeScript
  • CSS Modules
  • Express
  • Prisma
  • PostgreSQL
  • JWT

O desafio

Conectar o catálogo e o carrinho à operação da doceria, com registro de pedidos, identificação do cliente e controle de produtos e estoque de ingredientes.

Como resolvemos

A solução combina uma interface Next.js com uma API Express organizada por módulos e persistência no PostgreSQL via Prisma. O carrinho é mantido no navegador; o checkout autenticado registra o pedido e prepara uma mensagem com os itens para o WhatsApp. A área administrativa reúne pedidos, produtos e movimentações de ingredientes.
