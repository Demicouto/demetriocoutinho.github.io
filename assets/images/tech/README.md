# Ícones de tecnologias

Ícones originais do projeto Devicon, obtidos em 10/11/2026 pelo CDN jsDelivr:
https://github.com/devicons/devicon

TypeScript, React (para React Native), Expo, NestJS, Express, Prisma, Firebase, Tailwind CSS, Jest, Vitest, Swagger e Maven. Os arquivos SVG são utilizados sem alteração; os ícones monocromáticos têm o contraste adaptado pelo CSS no tema escuro.

NativeWind, Supertest e JDBC usam símbolos genéricos do Font Awesome já carregado pelo portfólio.
